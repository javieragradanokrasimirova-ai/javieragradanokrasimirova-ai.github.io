# Javier Agradano — Portfolio

Audience: recruiters and software teams considering a junior developer.
Sources: supplied CV and read-only LinkedIn profile presentation. Do not invent seniority, proficiency scores, testimonials or project outcomes.

UI/UX Pro Max consulted for a personal developer portfolio. The first match returned a documentation landing and was rejected. The narrower portfolio query returned a narrative structure and high-contrast editorial direction. Its casual typography is unsuitable for this professional brief; use Space Grotesk for headings and DM Sans for readable body text. Refine the palette to charcoal, warm paper and lime, with restrained borders and generous spacing.

Sections: introduction, two actual projects, profile, technologies with academic context, experience, education, languages and contact. Code illustration is decorative, GIS illustration explicitly conceptual, game image is an actual screenshot. The game was built with AI assistance, disclosed in the project.

Use semantic links and buttons, native dialog with Escape and focus return, visible focus, responsive single-column layouts and reduced-motion support. No contact form without a backend; use email and clipboard instead. No analytics or third-party app permissions. LinkedIn remains a normal outbound link.
